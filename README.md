# Gym Management System

## Overview

Gym Management System is a web-based application developed using ASP.NET MVC as part of the Backend .NET Diploma at Route Academy.

The system is designed for gym staff and administrators to manage daily gym operations efficiently through a centralized platform.

The project focuses on applying software engineering principles, building a maintainable application, and organizing business logic using N-Tier Architecture.

## Features

### Member Management
- Add, update, and manage gym members.
- Manage member information with business validations.
- Upload and manage member profile images securely.

### Trainer Management
- Add, update, and manage trainers.
- Organize trainer information.

### Memberships & Plans
- Create and manage membership plans.
- Manage member subscriptions and membership details.

### Sessions & Bookings
- Schedule and manage training sessions.
- Validate session capacity and dates.
- Manage bookings based on session availability and active memberships.

### Health Records
- Manage members' health records.
- Keep health-related information organized.

### Analytics Dashboard
- View gym statistics and insights.
- Monitor key gym activities through a centralized dashboard.

## Technologies Used

- **Framework:** ASP.NET MVC
- **Language:** C#
- **Database:** SQL Server
- **ORM:** Entity Framework Core
- **Data Access:** Repository Pattern & Unit of Work
- **Architecture:** N-Tier Architecture
- **Other Concepts:** LINQ, Auto Mapping, Dependency Injection, Authentication & Authorization, Exception Handling, Async Programming

## Architecture

The project follows N-Tier Architecture to separate responsibilities and improve code organization and maintainability.

It applies several software development principles and practices:

- Separation of Concerns
- Repository & Unit of Work Patterns
- Dependency Injection
- Clean Code Principles
- Business Logic Validation
- Asynchronous Programming
- Exception Handling

## Project Purpose

The main goal of this project is to simplify gym administration by providing an organized system for managing members, trainers, memberships, sessions, bookings, and health records.

It also serves as a practical application of backend development concepts and software design principles learned during the Backend .NET Diploma.
